User Manual - NexAgent Interactive UI

This is a user-controlled component library. Nothing happens automatically. You have to click buttons and perform actions yourself.

How to Use Buttons

Click any button in the Components tab. You will see:

  • A success message
  • A notification in the panel
  • A toast popup
  • The action counter increases
<button class="btn btn-primary" onclick="handleButtonClick('Primary')">
    Click Me
</button>

How to Use Cards

Cards have two ways to interact:

  • Click on the card body - Shows card info
  • Click on card button - Triggers specific action

How to Use Forms

  • Fill in your name, email, and message
  • Click "Send Message" to submit
  • Validation will check if fields are empty
  • Success shows a notification and toast

How to Create Notifications

Go to Interactive Zone tab and:

  • Click "Show Success Message" buttons
  • Type a custom message and send it
  • Each action creates a notification
  • Notifications appear in the right panel

How to See Toasts

Click any toast button in Interactive Zone:

  • Success Toast - Green, positive action
  • Error Toast - Red, something went wrong
  • Warning Toast - Yellow, caution message
  • Info Toast - Blue, information message
💡 Tip: All actions are manual. Nothing auto-refreshes. You are in complete control!
